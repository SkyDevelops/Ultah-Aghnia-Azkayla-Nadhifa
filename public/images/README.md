## ✅ Format yang Didukung

### Foto:
- `.jpg` / `.jpeg` (disarankan)
- `.png`
- `.webp`

### Video:
- `.mp4` (disarankan)
- `.webm`

## 💡 Tips
- Ukuran foto disarankan: maks **2MB** per file
- Ukuran video disarankan: maks **10MB** per file
- Resolusi foto ideal: **800x800px** atau lebih
- Jika file belum ada, akan tampil emoji placeholder otomatis
- Nama file HARUS sesuai tabel di atas (huruf kecil semua)
